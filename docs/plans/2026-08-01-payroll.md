# Výplatní pásky — implementační plán

## Fáze 1: Doména a výpočty

- Přidat migraci, enumy, modely, validity a servis výplatního reportu.
- Pokrýt výpočty, docházku, úpravy a životní cyklus servisními testy.

## Fáze 2: Webové rozhraní

- Přidat admin-only routy a controllery pro report, úpravy, uzavření a tisk.
- Přidat Inertia stránky, sidebar a překlady.

## Fáze 3: Finanční report

- Nahradit plánované mzdy výsledky pásek a vynutit pořadí uzavření.
- Zachovat mzdové overrides a uzavřené historické snapshoty.

## Fáze 4: Verifikace

- Doplnit controller, frontend a E2E pokrytí.
- Spustit formátování, úplnou kontrolu a runtime smoke.

## Rozšíření: zjednodušený přehled a detail pásky

- Přidat admin detail pásky pro brigádníka, prodejnu a měsíc.
- Zredukovat hlavní tabulku na výplatní souhrn s jedinou akcí Detail.
- Přesunout mzdový override, úpravy, docházku a individuální tisk na detail.
- Sjednotit obě tiskové varianty do jednoho přístupného menu.
- Pokrýt nový tok controller, frontend a E2E testy.
