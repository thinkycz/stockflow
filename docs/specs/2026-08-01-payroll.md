# Výplatní pásky brigádníků

## Cíl

Přidat admin-only měsíční výplatní report aktivní maloobchodní prodejny. Každá
páska kombinuje základ z plánovaných směn, kontrolní skutečnou docházku a
položkové spropitné nebo srážky.

## Požadavky

- Report je měsíční, vázaný na aktivní prodejnu a nepřístupný omezeným účtům.
- Základ je součet částek plánovaných směn; každá směna se zaokrouhlí na haléře.
- Docházka, pauzy, rozdíl proti plánu a neúplné či nepárované bloky jsou
  kontrolní informace a automatický základ nemění.
- Úpravy jsou samostatné kladné položky typu spropitné nebo srážka s povinným
  důvodem. Výsledná výplata nesmí být záporná.
- Otevřený report je živý. Uzavření uloží snapshot a zamkne úpravy; neúplná
  docházka pouze varuje. Znovuotevření zachová úpravy.
- Report lze vytisknout celý nebo pro jednoho brigádníka. Každá páska začíná
  na nové stránce a obsahuje směny, plán/skutečnost, úpravy a výslednou částku.
- Finanční report používá výsledné částky pásek. Nelze jej uzavřít před
  uzavřením výplatního reportu. Výplatní report nelze znovu otevřít, dokud je
  finanční report uzavřený.
- Mzdové override ve finančním reportu zůstávají podporované.

## Terminologie

- **Výplatní report**: jeden měsíc aktivní prodejny.
- **Výplatní páska**: agregovaný výsledek jednoho brigádníka.
- **Úprava odměny**: položkové spropitné nebo srážka.
