# Cold Whisk Oat Latte

Made with oat milk, matcha. Select the required variant before measuring ingredients.

## Equipment

- Mixing Bowl
- Whisk / Mixer
- Serving Cup

## S — With ice

### Ingredients

| Component       | Ingredient   | Amount | Unit |
| --------------- | ------------ | ------ | ---- |
| Cloud / topping | oat milk     | 100    | ml   |
| Cloud / topping | liquid sugar | 20     | ml   |
| Cloud / topping | matcha       | 3.5    | g    |

### Method

1. **Measure oat milk.** Add 100 ml oat milk to mixing bowl.
2. **Measure liquid sugar.** Add 20 ml liquid sugar to mixing bowl.
3. **Measure matcha.** Add 3.5 g matcha to mixing bowl.
4. **Whip the mixture.** Whip until smooth.
5. **Chill the drink.** Fill the serving cup with ice.
6. **Assemble the drink.** Pour the whipped latte into the serving cup.

## S — No ice

### Ingredients

| Component       | Ingredient   | Amount | Unit |
| --------------- | ------------ | ------ | ---- |
| Cloud / topping | oat milk     | 100    | ml   |
| Cloud / topping | liquid sugar | 25     | ml   |
| Cloud / topping | matcha       | 3.5    | g    |
| Drink base      | ice cubes    | 2–3    | —    |

### Method

1. **Measure oat milk.** Add 100 ml oat milk to mixing bowl.
2. **Measure liquid sugar.** Add 25 ml liquid sugar to mixing bowl.
3. **Measure matcha.** Add 3.5 g matcha to mixing bowl.
4. **Whip the mixture.** Whip until smooth.
5. **Measure ice cubes.** Add 2–3 ice cubes to the serving cup for chilling.
6. **Assemble the drink.** Pour the whipped latte into the serving cup.
7. **Top up the drink.** Top up with oat milk to the standard serving line.

### Tips

- This no-ice variant still uses 2–3 ice cubes for chilling. Keep the listed liquid and sweetener amounts; do not reuse the with-ice quantities.
