# Cream Cheese

Prepare the cream cheese batch before making drinks. Follow the selected batch size and the written timing carefully.

## Equipment

- Mixing Bowl
- Whisk / Mixer

## Batch

### Ingredients

| Component       | Ingredient                       | Amount | Unit |
| --------------- | -------------------------------- | ------ | ---- |
| Cloud / topping | whipping cream                   | 250    | ml   |
| Cloud / topping | sweetened condensed milk (Salko) | 100    | ml   |
| Cloud / topping | cream cheese                     | 100    | g    |
| Cloud / topping | milk                             | 90     | ml   |

### Method

1. **Measure whipping cream.** Add 250 ml whipping cream to mixing bowl.
2. **Measure sweetened condensed milk (Salko).** Add 100 ml sweetened condensed milk (Salko) to mixing bowl.
3. **Measure cream cheese.** Add 100 g cream cheese to mixing bowl.
4. **Measure milk.** Add 90 ml milk to mixing bowl.
5. **Mix until thick.** Mix until thick.

## 1 portion

### Ingredients

| Component       | Ingredient                       | Amount | Unit |
| --------------- | -------------------------------- | ------ | ---- |
| Cloud / topping | whipping cream                   | 50     | ml   |
| Cloud / topping | sweetened condensed milk (Salko) | 20     | ml   |
| Cloud / topping | milk                             | 20     | ml   |
| Cloud / topping | cream cheese                     | 10     | g    |

### Method

1. **Measure whipping cream.** Add 50 ml whipping cream to mixing bowl.
2. **Measure sweetened condensed milk (Salko).** Add 20 ml sweetened condensed milk (Salko) to mixing bowl.
3. **Measure milk.** Add 20 ml milk to mixing bowl.
4. **Measure cream cheese.** Add 10 g cream cheese to mixing bowl.
5. **Whip the cloud.** Whip until thick.

## Notes

Use within 5 days.
