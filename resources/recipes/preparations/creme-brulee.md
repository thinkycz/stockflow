# Crème Brûlée

Prepare the creme brulee batch before making drinks. Follow the selected batch size and the written timing carefully.

## Equipment

- Mixing Bowl

## Standard

### Ingredients

| Component       | Ingredient                       | Amount | Unit   |
| --------------- | -------------------------------- | ------ | ------ |
| Cloud / topping | whipping cream                   | 250    | ml     |
| Cloud / topping | crème brûlée powder              | 3      | scoops |
| Cloud / topping | milk                             | 50     | ml     |
| Cloud / topping | sweetened condensed milk (Salko) | 50     | ml     |

### Method

1. **Measure whipping cream.** Add 250 ml whipping cream to mixing bowl.
2. **Measure crème brûlée powder.** Add 3 standard scoops crème brûlée powder to mixing bowl.
3. **Measure milk.** Add 50 ml milk to mixing bowl.
4. **Measure sweetened condensed milk (Salko).** Add 50 ml sweetened condensed milk (Salko) to mixing bowl.
5. **Mix until thick.** Mix for 7–10 minutes, until thick.

## Notes

Use within 5 days.
